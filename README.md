A tiny stack virtual machine in TypeScript: one `main.ts` runs make.fun's tiny stack ISA — wrapping 32-bit arithmetic, a 256-value stack, calls, 256 words of memory, input and output, and all ten traps with their exact exit codes — and answers every instance of a set in one run. Built by an AI agent for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty, $100 in USDC.

## Run it

```sh
MAKEFUN_INPUT_DIR=./in MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Run it twice and the two outputs are byte-identical.
